# make check, list-gates, and a check that the two lists agree

Blocked by [Q3](Q3.md). Needs gates to list.

One command a contributor runs before asking for review, and a second that
**names** every gate it runs with what each one covers. The naming half is what
makes the first half trustworthy: a `check` target whose contents nobody can
enumerate is a target people stop believing covers what they need.

## The drift gate is the part worth copying exactly

A gate list tends to exist in three hand-kept copies — a `.PHONY` block, the
prose in `check:`'s own `##` help, and an enumeration in a testing doc. Every
gate-adding PR edits all three, concurrent branches conflict on all three, and
they drift anyway.

The fix is one source of truth (make variables) with the help text and the docs
**derived** from it, plus a `--check` mode asserting every consumer still agrees.
That last part is not optional: a derived list that can go stale silently is
worse than honest copies, because it reads as authoritative.

## Scope it to this repo's size

The pattern this borrows from covers dozens of gates across several modules.
Here it is a handful. Take the source-of-truth-plus-drift-check shape and skip
the fan-out machinery; a parallel gate runner earns its keep at a scale this
repo will not reach.

Fold the tracked-git-hooks target in while here — `make hooks` setting
`core.hooksPath` to a tracked `.githooks/`, so the backlog lint from
[Q18](Q18.md) and the shell gates from [Q22](Q22.md) also run pre-commit.
