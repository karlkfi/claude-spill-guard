# The tracked pre-commit hook cannot run on stock macOS bash

[Q35](Q35.md) says `scripts/check-tools.sh` is the one script whose
`#!/usr/bin/env bash` has to survive bash 3.2, and that for everything else the
unguarded `shopt -s inherit_errexit` is harmless because it runs under CI's
bash or a developer's Homebrew bash 5. There is a second exception, and it is
structural in the same way check-tools.sh is.

`.githooks/pre-commit` carries the bare `shopt -s inherit_errexit` at line 20,
two lines after `set -euo pipefail`. Under bash 3.2.57 that prints `invalid
shell option name` and exits 1 — measured 2026-08-23 on darwin 25.5:

```
$ /bin/bash .githooks/pre-commit
.githooks/pre-commit: line 20: shopt: inherit_errexit: invalid shell option name
$ echo $?
1
```

It dies before it reaches `make queue`, so the store gates the hook exists to
run never run. A non-zero exit from `pre-commit` blocks the commit, so on a
machine with no Homebrew bash the effect is that `git commit` fails outright,
with a shopt error naming an option the contributor never asked for. `make
hooks` is what installs it, so the failure arrives at the moment someone
follows the setup instructions.

The exposure is the same one Q35 argues for check-tools.sh: a git hook runs on
whatever the contributor has, and a contributor on a stock Mac is exactly the
case a fresh clone produces.

## Why Q22's gate does not close this

Q22 requires the **bare** `shopt -s inherit_errexit` in every executable
script. `.githooks/pre-commit` already has the bare form, so that gate passes
it unchanged and the breakage survives the gate that was meant to find it —
the gate would bless the file rather than flag it. Whichever shape Q35 settles
on, `.githooks/` has to be inside its scope, either as a second named
exemption or by allowing the guarded form.

The one-line repair is check-tools.sh's: `shopt -s inherit_errexit 2>/dev/null
|| true`, with the comment saying why. Filed rather than folded into the Q38
change that found it, because it is a different defect and because the shape
of the fix is Q35's decision to make.
