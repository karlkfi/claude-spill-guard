# A tool version passed as an action input is outside every pin gate

`action-pins` requires a 40-character commit SHA for every `uses:`, and that
works because a SHA is content-addressed: the name *is* the bytes. A version
string is not, so an action input choosing which binary to download resolves on
the day, and the gate reading `uses:` values cannot see it. Q57 was one instance
of that — `GORELEASER_VERSION` on the job holding `contents: write` and
`id-token: write` — and closing it moved the pin into
`scripts/install-goreleaser.py`, where the job refuses rather than a gate
reading.

The class is empty today, and that was measured rather than assumed. Two actions
in this tree install a third-party binary. `goreleaser/goreleaser-action` is
gone with Q57. `sigstore/cosign-installer` takes a `cosign-release` input this
repository does not set, and its default at the pinned SHA is `v3.0.6` written
into the action's own `action.yml`; at that SHA it hashes the bootstrap
download against a digest carried in the action and then verifies the requested
release's signature with that bootstrap. So the action's SHA does pin what it
installs, and `action-pins` covers it by covering the `uses:`.

Nothing keeps the class empty. The next action with a version input re-opens it
and every gate stays green, which is the same silence Q57 had.

What is not obvious is what to do about it, which is why this is a row rather
than a gate. No static reader can turn a version string into a claim about
bytes, so the most a check could assert is that a version-shaped `with:` key
exists and somebody should look — an ask rather than a pin, and this repository
has a rule about which of those is worth spending. It would also have to decide
about `python-version` and `go-version-file`, which name GitHub's own tool cache
rather than a third-party download, and a check that flags those is a check
people learn to skip. Deciding it might be as small as refusing
`goreleaser/goreleaser-action` by name, so the pin Q57 built cannot be undone by
re-adding the action that made it necessary.
