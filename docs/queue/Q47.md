# Text encoded in UTF-16 is skipped as binary and never scanned

`scan.IsBinary` skips a buffer holding a NUL byte in its first 8 KiB, which is
what [`docs/design/README.md`](../design/README.md#pipeline) specifies and what
one PNG at 55% of the benchmark corpus is there to remove. UTF-16 pays that
toll without being binary: every ASCII character carries a NUL byte beside it,
so a UTF-16 file trips the check on its second byte.

The consequence is a whole file class the scanner reports clean without reading
— and it reports it exactly the way it reports a file it read and found nothing
in, which is the shape this project treats as the defect rather than the
inconvenience. Windows tooling is where the encoding turns up: PowerShell
redirection wrote UTF-16LE by default before PowerShell 6, so a transcript, an
exported credential or a `.env` written by an older script on that platform is
a file this never opens. Windows is a shipped target.

## What this has to settle

The design's position on encoding is deliberate and worth keeping: a NUL and
nothing else, because a UTF-8 validity check takes a side the three language
prototypes disagreed on — Go keeps raw bytes where Rust and Python substitute
U+FFFD, so the same file is text in one and not in another. Any answer here has
to leave that intact.

Three shapes, and the choice is the item:

- **Decode on a BOM.** `FF FE` or `FE FF` in the first two bytes, decode to
  UTF-8, scan that. Cheap and exact, and it misses a BOM-less file.
- **Decode on a NUL pattern.** Alternating NULs across the sniff window is
  UTF-16 rather than binary. Catches the BOM-less case and is a heuristic,
  which is the thing the NUL check was chosen to avoid being.
- **Leave it and say so.** Document the gap in the pipeline section and in
  whatever the tool tells a user it covers. A stated gap is a different object
  from a silent one.

Offsets are the part that bites whichever is chosen: a finding reports a byte
offset, and an offset into a decoded buffer is not an offset into the file on
disk. Whatever decodes has to map back, or say which buffer the offset is in.
