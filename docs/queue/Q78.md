# Nothing gates the validator list against the code

`internal/rules/rules.go` declares the validator names; `docs/design/README.md`
§4 carries the normative "Name in `validators`" table a rule author is sent to
before writing one, and `CLAUDE.md` counts them in its layout table. All three
are hand-kept and nothing compares them.

Measured 2026-08-27, on a branch that had added two validators and updated
neither doc:

```
$ python3 -c "import re;print(len(re.findall(r'Validator = .([a-z0-9-]+).',open('internal/rules/rules.go').read())))"
8
$ grep -c 'aws-placeholder\|jwt-sample-key' docs/design/README.md
0
$ sed -n '21p' CLAUDE.md
| `internal/validate/` | The six validators. ... |
$ make check
EXIT=0
```

`make check` was green with the design doc six rows short and `CLAUDE.md` off
by two. It was caught by an independent reviewer reading the diff, which is the
one instrument that does not scale.

**This is the shape `gate-drift` and `status-drift` already answer for other
lists**, so the mechanism is settled and only the subject is new. `gate-drift`
holds `GATES` against the workflow's job list and the table in `CLAUDE.md`;
`status-drift` holds the README's status table against the tree. A third in the
same family reads the `Validator` constants and fails unless every one has a
row in the design doc's table and the `CLAUDE.md` count matches.

Three things to settle when writing it:

- **Parse the constants, not the map.** `validators` is a `map[Validator]bool`
  and the const block is the declaration; a name added to one and not the other
  is its own defect and the gate should see both and disagree loudly.
- **The count in `CLAUDE.md` is a word, not a digit** — "The six validators".
  Either the gate spells numbers or the doc stops counting. Prefer the second:
  a count in prose that a gate has to parse is a bad interface, and "the
  validators" reads no worse.
- **Fail on a name the gate cannot place**, rather than skipping it. A
  derived inventory that silently under-derives is the failure this whole
  family exists to prevent.

Q7's `precision` gate is the precedent for the failure text: say what drifted
and which file to edit, because the reader is a rule author who has just been
refused.
