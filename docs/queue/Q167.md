# The head peel is decided after substitution, bash decides it before

Since Q92, `internal/bash` carries each token's quote provenance and the head
peel reads it. The group loop in
`internal/hook/bash.go:152:k := bash.ShKeywordPeel(sub, segment.QuotedFrom)`
applies that provenance to `sub` -- the segment's tokens with the resolver's
variable map substituted in -- because `expand` rebuilds token for token and the
two stay index-aligned.

That is sound for quoting, which is the whole of what Q92 was about: no
substitution can move where quoting appeared in the word the lexer read. It is
not sound for **shape**. A word that becomes assignment-shaped only after
expansion is peeled here, and bash peels nothing:

```
n=LC_ALL; $n=C cat f
```

bash settles what a word is before it expands anything, so `$n=C` is not an
assignment prefix. The shell looks for a program named `LC_ALL=C`, fails, and
reads no file. This peels `LC_ALL=C`, finds `cat f` behind it, and scans `f`.

## Measured

Driven 2026-09-09 against a binary built from `f0a9ea4` plus the Q92 fix, with
`testdata/corpus/planted/aws-access-key-id.env` at `f`:

| command | bash reads | verdict |
|---|---|---|
| `cat f` -- control | `f` | deny |
| `n=LC_ALL; $n=C cat f` | nothing | **deny**, naming `f` |

bash's own reading, upstream's rather than re-derived: `n=foo; $n=x true` prints
`command not found` and leaves `foo` unset.

## Why it ranks below Q166

It is a false positive, not a fail-open. The call is blocked over a file bash
would never have opened -- noise, and precision is what this repo calls the
product -- but nothing crosses that should not. The reserved-word half behaves
the same way (`k=if; $k cat f` peels an `if` bash runs as a program), and one
fix covers both.

## Which way it gets built

Count the peel on the segment's **own** tokens and apply the two boundaries to
`sub` by index, rather than peeling `sub` with the raw provenance. That is
upstream's repair for the same class -- `claude-bouncer` #110 does it in the
workspace-guard group loop and in `substitution_bodies`, and gives the argument:
a peel decided after the rebuild is asking about a different word, so no
provenance can travel across it.

The four other consumers of the substituted head -- `altersGlobbing`,
`poisonVars`, `clobbersIFS`, `forLoopBinding` -- take the same two boundaries,
so the change is one pair of counts threaded through rather than five readings.
