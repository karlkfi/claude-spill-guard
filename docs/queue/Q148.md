# Three pages call the escape hatch an environment variable

`internal/hook/override.go` opens with the rule: never `os.Getenv`. The hatch
is `SPILL_GUARD_OVERRIDE=<reason>` as an inline assignment prefix on a `Bash`
command and nothing else, because an exported variable or a `settings.json`
`env` block is durable, silent, and writable by the model, and reading one
"would turn a per-call hatch into a standing one that nothing reports". The
property the code went out of its way to have is the one three pages deny:

| Site | What it says |
|---|---|
| `docs/design/README.md:46` | "The escape hatch is one env var." |
| `docs/releases/v0.1.0.md:7` | "the escape hatch is one environment variable." |
| `docs/releases/v0.2.0.md:7` | the same sentence, in the CAUTION banner |

`v0.2.0.md` contradicts itself: line 84 of the same file has it right, "read
only from an inline assignment prefix on a `Bash` command — never from the
environment". A reader auditing the escape hatches from the banner is told the
opposite of what the design decided and the code enforces. `PRIVACY.md` said
the same until Q130 corrected it, and Q130 was the only row that named the
claim; this row is where it lives now that Q130 is gone.

## What to build

Two of the three sites are not edits.

- **The release notes stay as published, and the v0.3.0 notes did say it
  right.** Their NOTE banner names the command-position prefix and says the two
  earlier banners were wrong on that word. That half is done; the design line
  below is what is left.
- **The design line is a one-word fix and belongs to whoever next opens
  `docs/design/README.md`.** It sat in a sibling lane's file during the run
  that found it and was in nobody's item, so it was reported rather than
  fixed. Any PR touching that section takes it: "one env var" → "one inline
  `SPILL_GUARD_OVERRIDE=` prefix on a `Bash` command".

The measurement that settles the wording is `override.go` itself and the tests
beside it, which read the prefix and never the environment. It does not need
re-taking.
