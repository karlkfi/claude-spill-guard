# Nothing drives the live harness, so fail-opens are invisible to CI

**Measure:** whether a Claude Code session can be driven from CI at all — a
`hooks.json` wired to a recording hook, a scripted prompt, and the transcript
read back. That answer decides whether this is a gate or a documented
limitation, and nothing else in the row can be settled before it.

Every gate here reads the tree: `test` compiles and runs Go, `precision` runs
the corpus, `no-network` walks the import graph. None of them puts a payload in
front of the real harness. The scanner's correctness depends on an undocumented
grammar it does not own — which characters end an `@` token, which encodings
arrive as text, what a splice looks like in a transcript — and that grammar is
readable only by driving it.

## What the batch of 2026-08-28 measured

Seven defects, filed as Q85, Q86, [Q91](Q91.md) and the rest.
**Every one was found by driving. None by reading. All seven were under a green
`make check` at the moment they were found.**

Five of the seven are fail-opens: a file crosses into the model's context and
the scanner reports clean. That class has no symptom and no reporter — a user's
whole experience of it is a session that felt fine. The one defect with a
natural reporter, an over-scan that read the working directory, was caught
inside a single review round.

**So the classes this project is already good at catching are the ones with a
feedback loop, and the class the product exists to prevent has none.**

## The three that are the same defect

- The trim set: the harness strips punctuation the resolver kept.
- `isPromptSpace`: ASCII-only where the harness splits on U+00A0.
- `unicode.IsSpace`: returns false for U+FEFF, because Unicode removed it from
  `White_Space` in 4.0.1, and the harness splits on it anyway.

The third is the one that makes this a row rather than a caution. It is not a
hand-picked table a reviewer would squint at — it is the standard-library call,
the version that reads as authoritative and forecloses the question *where did
these characters come from*. **The stdlib idiom is the more dangerous of the
two, not the safer one.**

## What a gate would have to do, and why it may not exist

Driving a real session in CI means a Claude Code binary, credentials, and a
transcript to read — none of which this repo has or wants. A fixture recording
the harness's answers is the cheap substitute and is what
`internal/hook/testdata/prompt-oracle.json` already is; the gap is that nothing
re-runs the live measurement, so the fixture drifts silently from the harness
it stands in for and no check can tell.

So the honest outcomes are a gate, or a stated limitation in
[`docs/design/README.md`](../design/README.md) naming this as the class CI does
not cover and the fixture as what stands in for it. The second is a real answer
and is worth more than a gate that cannot fail.
