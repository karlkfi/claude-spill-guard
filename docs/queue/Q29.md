# Pull queue.py's upstream provenance fix, and record that it is vendored

`scripts/queue.py` is 1092 lines of backlog tooling with no record in the repo
of where it came from. It is a copy of the `session-backlog` skill's script,
and the two have already diverged. Measured 2026-08-21 with `diff`, before the
store gate landed: three prose hunks, all in the same direction — this copy
names `github-actions-gateway` as the source of the rank algebra in its module
docstring, its `# --- rank algebra ---` comment and its `rank --help`, and the
skill's copy describes the same contract without naming a repository.

Those three hunks are not drift in both directions. Upstream settled them in
one commit, `effd161` of 2026-08-21, "keep third-party provenance out of the
vendored file" — the reasoning being that `queue.py` is copied verbatim, so
every line in it lands in someone else's repository as a byproduct of taking
the skill. This repo vendored at `93830cf`, before that, and has not updated
since. So the question is not which way to sync but that nothing here pulls.

The store gate then widened the fork on purpose. `blocked-opener` and
`dangling-link` grew a second message branch for the case where the blocker has
shipped, because the single-branch wording sent a completing session to restore
a dependency that no longer existed. That belongs upstream: every repo running
the skill has the same defect and none of them get the fix from here.

Three things to settle:

- **Take `effd161`.** The provenance decision is made; this copy just has not
  received it. Re-vendor, or port the three hunks by hand and say which.
- **Record that the file is vendored, and from what.** Nothing in the repo says
  so today, which is what made the divergence invisible for six days. Whatever
  form this takes has to survive `effd161`'s own rule — it travels into the
  next repo that copies the file.
- **Push the two message branches up.** They are the reason this is queued
  rather than parked. `karlkfi/claude-skills` is private, so this is an issue
  or a PR there rather than a public filing; the draft still gets read before
  it goes, per repo policy.

The three prose hunks are the low-stakes half; the same mechanism silently
strands a defect fix, which is not.
