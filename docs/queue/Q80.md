# Test credential values live in nine test files, not in the corpus

Nine `_test.go` files carry a literal shaped like an AWS key ID:
`cmd/spill-guard/main_test.go`, `internal/hook/hook_test.go`,
`internal/rules/capture_test.go`, `internal/rules/load_test.go`,
`internal/scan/decode_test.go`, `internal/scan/prefilter_test.go`,
`internal/scan/scan_test.go`,
[`internal/validate/aws_test.go`](../../internal/validate/aws_test.go) and
`internal/validate/entropy_test.go`.

GitHub's detector for the `ASIA` prefix opened an alert on the last-but-one of
those on 2026-08-27, and PR #45 answered it by adding that one file to
`paths-ignore` in [`.github/secret_scanning.yml`](../../.github/secret_scanning.yml).
That is an exemption on a source file, which is a worse thing to own than an
exemption on a directory of fixtures: it is one file the scanner no longer
reads, and it covers one of the nine. Which of the other eight stay quiet
depends on which detectors GitHub ships next, not on anything this repository
controls.

## The shape

Named values in a corpus-resident JSON file; tables stay in Go. A row keeps
its name, its expectation and its comment where a reviewer reads them, and
takes its value by id.

Two mechanics are already measured. `corpus_test.go` only ever joins
`corpusRoot` with `clean` or `planted` and nothing enumerates the root, so a
third directory under `testdata/corpus/` sits outside the precision gate while
inside the `testdata/corpus/**` glob that `paths-ignore` already carries. And
content arriving under an excluded path resolves on arrival rather than
blocking the push: alerts 2 through 9 on this repository were created and
resolved in the same second as `hidden_by_config`, on the push that added the
corpus, because the exclusion had merged first.

JSON rather than YAML: `encoding/json` is stdlib and a YAML parser is a
dependency, and a test-only dependency is still a dependency in a project whose
premise is that the supply chain is empty.

## What stays inline

A string no detector can mistake for a credential does not need to move, and
moving it costs a reader the bytes under test. `AKIAIOSFODNN7EXAMPLES` is 21
characters, so the trailing `\b` cannot match; `AKIAIOSFODNN7example` fails
`[A-Z0-9]`; `AKIAXXXXXXXXXXXXXXXX` is what the entropy floor exists to drop.
Those are the validator's edge cases and they belong at the assertion site.
The rule is whether the string could pass for an issued credential, which does
not depend on the detector roster.

## The floor

The loader fails the test on a read error, and asserts a minimum row count the
way `minCleanFiles` does in `corpus_test.go`. A vectors file that loads nothing
turns every table that reads it into a vacuous pass, and a table test reporting
zero cases reports the same green as one reporting forty.

Completing this drops the `internal/validate/aws_test.go` entry from
`.github/secret_scanning.yml`, which is the check on whether it worked.
