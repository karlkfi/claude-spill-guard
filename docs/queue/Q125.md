# Twenty-two tracked files trip the scanner, and thirteen should

[Q121](Q121.md) measured one file and said the census was not taken. It is taken
now, and the class it named is seven files rather than one — but the useful
finding is the other two thirds of the result, which is that a gate over this
cannot be *no tracked file may trip the scanner*. Thirteen of the twenty-two are
supposed to match.

Driven 2026-09-03 on a binary built from `bc7068f`: every tracked file through
`spill-guard hook` as a `Read` payload, 222 files, 22 denied.

| Population | Files | Should a gate fire on it? |
|---|---|---|
| `testdata/corpus/planted/` | 12 | **No.** Each holds exactly one planted secret by specification |
| `testdata/corpus/vectors/credentials.json` | 1 | **No.** The home CLAUDE.md names for credential-shaped test input |
| Go source with an inline credential-shaped literal | 7 | **Yes.** This is Q121's class |
| Markdown carrying an example credential shape | 2 | **Undecided**, and it is the interesting one |

## The seven in Q121's class

`cmd/spill-guard/main_test.go`, `internal/hook/hook_test.go`,
`internal/rules/capture_test.go`, `internal/scan/decode_test.go`,
`internal/selftest/selftest.go`, `internal/testvec/vectors_test.go`,
`internal/validate/jwt_test.go`.

Two of those are worth naming separately. **`internal/selftest/selftest.go` is
not a test** — it is shipped source, compiled into the binary, and it carries the
canary payloads that make `selftest` work. Moving its literal into
`testdata/corpus/vectors/` would mean the shipped binary reading a testdata file
at run time, which it must not do, so the fix Q121 proposes does not reach this
one and a different answer is needed for it.

And **`internal/testvec/vectors_test.go` is the loader test for the very
directory the literals are supposed to live in**, carrying two matches inline. The
convention's own test does not follow the convention.

## Nothing excludes the corpus, and CLAUDE.md reads as though something does

CLAUDE.md calls `testdata/corpus/vectors/` "the credential-shaped strings the
unit tests read, kept where secret scanning is told not to look." No mechanism in
this repository does that telling. There is no ignore file of any kind tracked
here, and the shipped scanner has no path-exclusion arm — `rules/spill-guard.json`
is the only scanner config in the tree and it carries rules, not paths. Measured
directly rather than inferred: a `Read` of `testdata/corpus/vectors/credentials.json`
is denied naming five rules.

That sentence may be true of GitHub's own push protection, which is configured
off the tree and was not checked here. It is not true of spill-guard, and
spill-guard is the scanner a session runs.

## The three things to settle

- **What the gate asserts.** Not "no tracked file trips the scanner" — that
  fails on the planted corpus by design, and a gate whose first run must be
  suppressed for thirteen files teaches everyone to suppress it. The candidate
  is an allowlist of paths that are *expected* to match, so the gate reports a
  file entering the class rather than the class existing. That inverts cheaply
  into the property worth having: a new inline literal reddens the PR that adds
  it.
- **Whether the two Markdown files are in scope.** `README.md` denies at byte
  8868 and `testdata/corpus/README.md` at three offsets. The first is the
  repository's front page: a session running this plugin cannot read the README
  of the plugin it is running. Whether that is a defect to fix or a documented
  consequence to state is the call this row does not take — masking the examples
  would cost the docs the thing they are demonstrating.
- **Whether `selftest.go` can be fixed at all**, given the shipped binary cannot
  read testdata. If it cannot, the allowlist has a permanent member and the gate
  has to say why.

## Why this is M, and why it is not Q121

Q121 is one literal moving into `testvec`, and it stays S and stays worth doing.
This is a gate with an allowlist, a decision about docs, and a case the proposed
fix cannot reach. Folding them together would let the easy half close the row and
carry the rest into history — which is how the census went untaken the first
time.
