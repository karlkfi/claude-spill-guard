# install.sh and install.ps1, exercised on all three OSes

Blocked by [Q11](Q11.md). Needs artifacts to install.

Both scripts live in this repo so they are reviewable at a versioned URL. Each
detects OS and architecture, downloads the matching archive, verifies the
sha256 against `checksums.txt`, verifies the Sigstore signature when `cosign`
is present, and installs to `~/.local/bin` or `%LOCALAPPDATA%`.

**The documented form is two steps — download, read, run.** The one-liner that
pipes into a shell will work and is not what the README leads with. For a tool
whose pitch is that nothing leaves your machine, opening with "pipe this remote
script into your shell" undercuts the claim before a reader reaches the second
paragraph.

CI runs both scripts on all three operating systems every release. An install
script that broke is indistinguishable from a tool nobody installed, so this
needs a mutation control like the launcher's: break the checksum comparison and
require the job to go red.

## The open question this item carries

Whether `install.sh` should refuse to proceed when `cosign` is absent. Failing
closed is the rule everywhere else in this project, and most machines do not
have cosign installed, so the strict reading makes the fallback channel
unusable for most of the people it exists for.
