# Ship us-ssn enabled

The project's first line says it stops secrets and PII, and all four numeric PII
rules ship off with nothing able to enable them, so that half of the sentence is
false. Karl chose on 2026-11-03, after the firing-rate and cost measurement, to
enable `us-ssn` alone. `payment-card` stayed off on that measurement, which Q33
now carries; `cn-resident-id` and `ipv4-public` were never in question.
