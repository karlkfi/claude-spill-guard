# The corpus README counts six private-key fixtures and planted/ has seven

`testdata/corpus/README.md` says six files carry `private-key-block` and lists six layouts, and `testdata/corpus/planted/` holds seven.
The seventh is `private-key-block-in-grep-output.txt`, added by Q206 in #204 and described only in `rules/README.md`.

The README's other claim about the six holds: they share one key body, and the seventh carries its own.
Checked 2026-11-26 by comparing each fixture's base64 runs by suffix — six share a line with `private-key-block.pem` and the grep-output file shares none — without printing any of them.
So the fix is the count, the seventh layout in the list, and a sentence on why its body differs, which `rules/README.md` under Q206's change is the place to read first.
