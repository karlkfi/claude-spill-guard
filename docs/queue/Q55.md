# The status gate has no control for a missing marker pair

`scripts/check-status.py` handles the `status:begin` / `status:end` markers
being absent — `block()` returns `None` and `check()` appends *"has no
`status:begin` and `status:end` markers, so the status table is not generated
and nothing keeps it current"*. Nothing drives that path.

`status-drift-mutation-control` has three steps, and each mutates something the
gate then reads: a hand-edited table, the scanner wired into `main.go`, a `case`
arm the usage text does not name. All three assume the block is there to read.
So the one branch nobody tests is the branch that decides whether the gate
inspects anything at all.

That is the gate's own subject. It exists because a status claim that goes
stale silently reads as authoritative; a gate that has quietly stopped looking
at the block reads exactly the same way, and passes.

## The mutation, and the thing it has to assert

Delete the two marker lines from `README.md`, assert the deletion landed, and
require `make status-drift` red on `has no` — not merely red, since a tree with
no markers also fails the table comparison for a different reason and the two
are indistinguishable from an exit code.

Worth pinning the rewrite half in the same step: with the markers gone,
`make status` must **exit non-zero and change nothing**, rather than appending a
fresh block somewhere or silently succeeding. `write()` calls `sys.exit` on that
path today and no case proves it.

## Why it is `S` and near the tail

The path is written and reads correctly by inspection; the gap is that
inspection is all that stands behind it. Nothing in the tree removes those
markers today, and the file they live in is generated rather than hand-edited,
so the exposure is a future contributor rewriting the Status section by hand —
which is the case the gate was built for and the one case it cannot currently
prove it catches.

Filed from the retrospective on the 2026-08-25 batch, where five mutation
controls in one run passed while testing nothing. This is the same shape caught
before it fires rather than after.
