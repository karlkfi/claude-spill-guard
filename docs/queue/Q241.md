# `language-choice.md`'s rule counts sum to 5,684 against a stated 5,679

`docs/design/language-choice.md` says the inherited ruleset produced 5,679 matches
on 257 files, and the nine per-rule counts beside it add up to 5,684. The README
quoted both until the review of #233 found it, and now says "more than 5,600".

The corpus is not in this repository, so nothing here can say which figure is
wrong. 5,679 is also cited in `docs/design/README.md`, `docs/design/brief.md`, `rules/README.md`, `testdata/corpus/README.md`.

## The fix

If the corpus can be re-run, re-take the count and correct every site. If it
cannot, say in `language-choice.md` that the two figures disagree by 5 and that
the corpus is gone, so the next reader does not spend the time re-adding them.
