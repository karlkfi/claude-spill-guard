# The scanner has no budget of its own, and the harness allows on expiry

`hooks/hooks.json` gives the hook 60 seconds, and
[what happens at the ceiling is now measured](../design/README.md#the-third-shape-is-a-timeout-and-it-is-the-one-this-repo-configures):
the hook is killed, its verdict is discarded, and **the call proceeds**. Both
events, driven 2026-09-03 against Claude Code 2.1.251.

Nothing the hook writes prevents that. A killed process writes nothing, so
neither the `deny` object nor exit 2 is available to it — the two shapes the
exit-code contract is built on are both out of reach at the one moment they are
needed. The only place a deadline can live is inside the scanner, and there is
none: `internal/hook` reads an operand with `os.ReadFile` under no size cap, and
no stage of the pipeline carries one.

So the fail-open is reachable by size alone. A `Read` of a large enough file, or
a `Bash` reader operand pointing at one, runs past 60 seconds and the call goes
through with nothing scanned. That is the class [Q94](Q94.md) names — no
symptom, no reporter, invisible to every gate that reads the tree — and here it
needs no exotic input, only a big one.

**How big "big enough" is has not been measured.** Nobody has run the pipeline
against a file large enough to approach the ceiling, so whether ordinary input
reaches it or only a pathological one does is open. That changes how the fix is
shaped, not whether it is needed.

**Why this is M.** A deadline that fires has to decide something, and the only
decision that keeps the product's own promise is to block — a blocking reason on
a buffer with no finding behind it, which is the branch `blocks` in
[`internal/hook/hook.go`](../../internal/hook/hook.go) already carries for a
skip. Then the budget itself has to be picked well inside 60 seconds and picked
against a benchmark rather than a preference. A size cap is the cheaper half and
does not replace it: a cap answers before reading and a deadline answers during,
and a directory walk has no size to cap.

That last clause is why [Q95](Q95.md) is worth reading beside this one. Walking
a tree is unbounded, so at the deadline it converts into an allow; refusing does
not.
