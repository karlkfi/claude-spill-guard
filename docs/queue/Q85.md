# The skip verdict is per reason, and the argument under it is per surface

Q74 decided what an unread buffer does per skip reason: a declared encoding this
build cannot decode blocks, and the binary skip does not. The second half rests
on one argument — denying every image read gets the hook uninstalled, and an
uninstalled scanner enforces nothing — and that argument is about `Read`. It was
applied to both surfaces because the reason is what `internal/hook`'s `blocks`
is given, and the surface is not.

On `Bash` it is much weaker. `cat core.dump` sends the file's bytes to the model
as command output, and nobody runs that on a PNG by accident the way a session
opens an image on purpose. So the population that makes the allow necessary on
`Read` is largely absent from the operand path, while the population that makes
it cost something — a heap dump, a `.pack`, an SQLite file with a token in it —
is most of what a reader is pointed at when the operand is binary at all.

## A third surface, and the only arm anybody has measured

Once a prompt resolves its `@` tokens the same verdict governs them, and that
surface is sharper still: an `@` token is typed deliberately, one file at a
time, so the accidental-image case that carries the allow on `Read` has no
counterpart at all.

Driven against Claude Code 2.1.238 rather than argued, and it comes back as two
arms with the harmless one being the one that springs to mind:

| Prompt token | How it crosses |
|---|---|
| `@logo.png` | as an image, no text content — nothing a rule could match goes anywhere |
| `@heap.dump` | as **text, in full, including the NUL** |

Then through the built binary, with the control beside it, since exit 0 on empty
stdout is otherwise indistinguishable from a hook that never ran: an AWS-shaped
key with no NUL blocks and names the rule and the path; the same key placed
after a NUL exits 0 with empty stdout and is allowed. So the credential reaches
the model's context under a clean report, and the population that does it is not
images.

## What it does not settle

Whether the split is worth having. A verdict keyed on reason and surface is two
policies where there is now one. One arm is now measured and the others are not:
nothing says how often a session `cat`s a buffer with a NUL in the first 8 KiB.
Take that before writing the branch, because a split that fires on nothing is a
second policy to keep true for no gain.

Note which way the prompt measurement cuts. It does not show the allow is wrong
in general — it shows the argument carrying it is about images, and that the
buffers actually carrying secrets are the ones the argument never covered.
[`Q91`](Q91.md) reaches the same place from the classification side.

`internal/hook/hook.go`'s `blocks` takes a `scan.Skip` and nothing else, so
giving it the surface is a signature change and the argument for it lives in the
same comment. `docs/design/README.md`, "An unread buffer is not a clean one",
carries the per-reason half and would grow the second axis.
