# An unsettled operand list hides a literal beside it

`docs/design/README.md` says a gap does not hide a finding beside it, and names
this as the exception. The walk goes on past one operand it cannot settle. Where
the whole operand list is unsettled it reads nothing on the line, so a literal
holding a key crosses with only a record. Driven 2026-11-04 on bash 5.3.15 with
`key.txt` holding a key:

| Command | Hook | bash prints the key |
|---|---|---|
| `echo plain.txt \| xargs cat key.txt` | no verdict, one record | yes |
| `timeout $T cat key.txt`, with `T=5` in the environment | no verdict, one record | yes |
| `timeout "$(echo 5)" cat key.txt` | no verdict, one record | yes |
| `for f in $(echo plain.txt) key.txt; do cat "$f"; done` | no verdict, one record | yes |
| `wc --files0-from=list.txt key.txt` | no verdict, one record | not run: `wc` here is BSD and rejects the flag |

The first three are the `wrap.Opaque` arm in `internal/hook/bash.go`, the last the
`readers.Indirect` arm just below it, and the `for` row is `vars.go` poisoning the
name on an item that is not a literal.

**An unquoted substitution is not in this list, and the difference is not
principled.** `timeout $(echo 5) cat key.txt` denies and the quoted form above
does not. Q252 kept that deny, because the unquoted form denied before it and
reading it deferred would have regressed the shape, and left the deliberate arms
as they were, because the reviewer who found them read them as deliberate.

The question is whether a literal after a known reader's name should get its
verdict whatever else on the line is unsettled, with the record beside it. The
cost to measure first: a wrapper whose grammar was lost starts the command at the
first later word naming a reader (`scanForCommand`), so `timeout $T foo cat
key.txt` would block over a file `foo` was handed. How often that shape occurs is
unmeasured. `readers.Indirect`'s comment also says the list itself is scanned, and
the arm continues before anything is, so that sentence is false as it stands.

**Done** is either the arms read their literals and the design's exception goes,
or a measurement that says why they should not, written beside that exception.
