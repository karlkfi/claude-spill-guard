# The corpus README names a value `aws-access-key-id.env` stopped carrying

[`testdata/corpus/README.md`](../../testdata/corpus/README.md), under **Adding
to it**, opens its worked example by saying `aws-access-key-id.env` carries
`AKIAIOSFODNN7EXAMPLE`, the key AWS publishes on its own IAM pages. It does
not. The file carries the fabricated `ZmT4bXn9Ld6VcP1`-stem value, uppercased —
measured 2026-09-04 by reading both. The same README says so forty lines up:
"It used to carry `AKIAIOSFODNN7EXAMPLE` ... and the rule now drops that key on
the `EXAMPLE` suffix." The two paragraphs contradict each other and the earlier
one is right.

The argument the passage makes is sound and is why the paragraph is worth
keeping: a planted fixture has to be **found**, so it cannot be marked by the
string the scanner is being taught to reject. What went stale is the tense. A
reader following "it carries" greps the file, finds a different value, and has
to work out which sentence to believe.

**The repair is not just the tense**, which is why this is a row rather than a
word. The passage goes on to name the `0SPILLGUARD` mark that replaced it, and
that value is in `aws-access-key-id-utf16le.env` — a third file, never named in
the passage. So the worked example spans two files and reads as one. Decide
which file the example is about, say the other one carries the mark too, and
re-read the neighbouring stem paragraph, corrected for this same class in the
Q81 pull request.

**Do not repair it by quoting the two values here.** `docs/queue/` is outside
[`.github/secret_scanning.yml`](../../.github/secret_scanning.yml)'s
`testdata/corpus/**` exclusion, so a fixture value written into a row is the
shape [Q121](Q121.md) is about — a credential-shaped literal in a file whose
own reads then block. Both values are one `grep` away in the corpus.

**This is a docs defect with a gate-shaped question behind it.** Nothing walks
this README comparing a quoted literal to the file it attributes it to, and the
class recurs — [Q68](Q68.md) is the row about a measured figure going stale
inside its own branch. A quoted fixture value is narrower and checkable: the
README names a file and a literal in one sentence, which a lint could read.
Whether that is worth building is the open half.

Found while working Q81, which added a planted file under this section's rules
and had to read them closely to do it. That row is completed and gone from the
store, so the reference is to `git log` rather than to a file — a link here
would dangle.
