# CLAUDE.md records only the artifact form of a measured case

[`CLAUDE.md`](../../CLAUDE.md), under *A mutation control needs a precondition
asserting the mutation had its effect*, says:

> The checkable form is comparison against a case already measured, and **the
> case is a file, not a recipe for producing one.**

That is one checkable form, written from the launcher repair, where what the
mutation acts on is an **artifact** — bytes whose exact identity is the whole
property, and which nothing but a hash can pin. It is right there and it is not
the only one.

Where the mutation acts on **behaviour**, the checkable form is to drive the
mutated subject and assert the symptom directly, and no file can stand in: the
`test` control's mutation flips a `return` and there is no artifact to hash,
only a binary to run. Three preconditions added under Q103 are of that second
shape, and each was driven both ways:

| Control | The mutated subject, driven | The symptom asserted |
|---|---|---|
| `doctor` | `go -C tools list -deps ./...` in the mutated environment | must fail, or `tools/` was never unreachable |
| `test` | the binary built from the mutated source | must exit 0 on an unknown command |
| `vulns` | govulncheck over the mutated module | must name `GO-2021-0113` |

**The discrimination between the two forms already exists and is in the wrong
place.** Q103 carries it — a hashed artifact earns its cost only where the
mutation is sensitive to something other than its own edit — and Q103 is
scheduled to disappear when its residue closes. `CLAUDE.md` is what persists,
and it currently states the artifact form as though it were the general one, so
the next control written against a behavioural subject reads that passage and
finds no case that fits.

Write the second form beside the first, with the test that picks between them,
and shorten rather than add: `CLAUDE.md` is re-read every session and the
passage is already six paragraphs. The launcher narrative can carry the
discrimination without a seventh.

Filed rather than taken inside Q103's pull request, for two reasons worth
keeping: the change was proposed by a reviewing session rather than by the
maintainer, and `CLAUDE.md` is the file that instructs every later session, so
it is not one to edit on a peer's say-so; and #71 was green and handed back
when it came up.
