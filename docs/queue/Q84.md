# An allowed skip tells nobody, and the design said it would

`docs/design/README.md` step 6 ends: every path that declines to read "names its
reason and the caller carries that as far as the user". Q74 made the caller read
the reason and act on it, and half of that sentence is still unmet. A blocking
skip carries its reason in the deny — a user meeting a UTF-32 file is told the
encoding and can act. The binary skip is allowed, and allowed means exit 0 with
an empty stdout, so nothing reaches anyone at all.

That is the one silence `internal/hook` produces which is not a scan that ran,
and the package doc now says so rather than claiming otherwise. Saying so is not
closing it.

## Why it is not a one-line emit

There is no measured encoding for it. `internal/hook/verdict.go` carries two
shapes and both of them block; what a `PreToolUse` hook can put in front of a
user *without* blocking is unmeasured here, and this repo does not take that
kind of answer from documentation — the predecessor failed open on Node 18 for
exactly that reason. So the work starts with a drive against a real Claude Code,
the way the exit-code table was taken: whether hook stderr on exit 0 surfaces
anywhere, whether a `systemMessage` field is delivered on an allow, and which of
those reaches the human rather than the model.

The distinction matters more here than usual. A skip notice is for the person,
who can convert a file or set an override; routing it to the model spends
context on every image read and tells the one party that cannot act on it.

## What makes it worth the drive

Text lands in the binary skip and is allowed with it. That used to be true in
two ways rather than one, and Q91 closed the second: a UTF-16 mark whose decoded
sniff window holds a `U+0000` now returns its own skip reason and blocks, so its
user is told the encoding and can act. What is left here is the first way, and
it is the harder one — UTF-16 written with **no** byte-order mark, where nothing
declares anything, so there is no encoding to name and no ruling available about
which rule wins. It is readable text a secret sits in, and it is allowed in
silence.

Telling the user their file went unread is the remedy that needs neither a guess
at an encoding nor a ruling of any kind, and today they are told nothing. Q91
narrowed this row rather than replacing it: every buffer still in the allowed
skip is one nothing can name, which is exactly the population a bare notice
serves and a better reason serves not at all.

An override does not stand in for it: `SPILL_GUARD_OVERRIDE` is a way past a
block, and there is no block here to get past.
