# zsh precommand modifiers and `repeat` hide the reader behind them

`noglob`, `nocorrect` and `repeat N` run the next word as the command in zsh,
and in bash they are unknown commands that read nothing. The wrapper peel in
`internal/readers/wrappers.go` knows none of them. Under zsh the reader behind
one is therefore never looked up, and its file crosses with no verdict and no
record. `coproc` is the same gap in both shells.

Driven 2026-11-01 on the v0.6.0 binary as a zsh machine sees it
(`SHELL=/bin/zsh`, no `CLAUDE_CODE_SHELL`), over a scratch `k.env` holding the
planted AWS key. A shell column reads `reads` when `env -i <shell> -c`
printed the key.

| command | bash 5.3.15 | zsh 5.9 `-f` | hook |
|---|---|---|---|
| `cat k.env` (control) | reads | reads | deny |
| `noglob cat k.env` | no | reads | silent |
| `nocorrect cat k.env` | no | reads | silent |
| `repeat 1 cat k.env` | no | reads | silent |
| `coproc cat k.env; sleep 1; cat <&p` | no | reads | silent |
| `coproc cat k.env` | -- | -- | silent under `SHELL=bash` too |
| `time cat k.env` | reads | reads | deny |

`time` is already peeled. Of the zsh precommand modifiers, `-`, `builtin`,
`command` and `exec` are covered: `- cat k.env` read nothing under `zsh -f`,
and the other three are already in the peel (Q196). The bash `coproc` row
shows only that the hook is silent. `cat` opens the file whoever reads the
pipe, but a drive that reads the key back through `${COPROC[0]}` in bash
failed (`Bad file descriptor`), so the bash arm crossing is unmeasured.

**Peel them, rather than refusing on the word under zsh.** Their grammar is
exact and upstream's wrapper rows already have the shape. `repeat` consumes
one count, and the modifiers consume nothing. Peeling them under bash too
costs at most a scan of a file an unknown command would not open, which is
the safe direction. Whether to make the peel unconditional or keep it to zsh
is the implementer's call.

**Done** is the table pinned in a hook test under both shell settings, and the
`coproc` bash arm either driven or stated as unmeasured in the test's comment.
