# Detect Anthropic API keys

This scanner exists to stop secrets reaching the Anthropic API, and it does not
recognise an Anthropic API key. Measured 2026-11-03 on a binary built from
efac304: a synthetic `sk-ant-api03-` value with a 95-byte body ending `AA`
through `spill-guard filter` exits 0, with an AWS-shaped positive control
exiting 3. `openai-api-key` opens on the same `sk-` and needs an embedded
`T3BlbkFJ`, so it cannot reach one.

Anthropic publishes no format. What can be cited is what detectors ship: gitleaks and
TruffleHog both match `sk-ant-api03-` and `sk-ant-admin01-` with 93 bytes of
`[A-Za-z0-9_-]` and a closing `AA`, TruffleHog verifying hits against the
live API; OpenRouter's guardrail docs name the same two prefixes and the `AA`
tail, with no length.

Add the rule with its planted fixtures and a clean-corpus placeholder.
