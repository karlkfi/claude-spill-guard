# Plugin manifests and hooks.json

`.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json` and
`hooks/hooks.json` are deliberately absent from the repo until there is a hook
that fires. Shipping them earlier makes the repo installable as a security tool
that scans nothing, which is the failure the design indicts the predecessor
for — installed, silent, enforcing nothing.

So this is the item that makes the plugin real, and it lands with or after the
launcher rather than before it.

Copy the manifest shape from the sibling guards: eight keys in `plugin.json`,
a single-plugin `marketplace.json` pointing at this repo, versions kept
identical between the two. Nothing else in the repo encodes the version.

Wire the `PreToolUse` matcher against the tools the design's hook-surface table
settles on. That table is settled: `PostToolUse` cannot withhold a result, so
every tool this guard actually stops has to be matched at `PreToolUse`.

**The matcher has to name exactly what `internal/hook` scans, and that is
three buffers across two events.** `PreToolUse` on `Read` and on `Bash`, and
`UserPromptSubmit`, which scans the prompt text: `targets` switches on the
event before it reaches any tool name, and the prompt arm is
`internal/hook/hook.go:119:case UserPromptSubmit:`.

The two ways of getting it wrong fail in opposite directions and only one of
them is loud. A matcher wider than the scanner delivers calls the hook returns
clean on without having looked at them. An event the scanner handles and the
manifest omits is worse, because nothing fires at all — no payload, no verdict,
no line in the transcript — so the prompt surface is simply absent and reads
exactly like a prompt that carried no secret. Both are the failure this repo
indicts its predecessor for.

`UserPromptSubmit` is not a tool event and takes no matcher, so it is a second
entry in `hooks.json` rather than a third name inside the first one. `ToolRead`
and `ToolBash` are exported from that package so the `PreToolUse` half can be
held to those constants rather than kept in step by hand.
