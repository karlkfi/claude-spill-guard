# Homebrew tap for macOS and Linux

`karlkfi/homebrew-tap`, giving `brew install karlkfi/tap/spill-guard`. One
channel covers both platforms, since Homebrew runs on Linux.

A personal tap is self-hosted with no third-party review — `homebrew-core` is
the one that costs review and a notability bar. The formula pins the archive's
sha256, so Homebrew verifies integrity at install with nothing extra asked of
the user.

Maintenance is a release-workflow step that opens a PR on the tap with the new
version and checksums. Wire that in the same PR as the tap itself; a tap
updated by hand is a tap that is one release behind within a month.
