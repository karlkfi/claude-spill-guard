# A shell option restored from the rc file changes what a glob sends

`globFiles` expands a pattern under bash's default options, and the argument for
that is a measurement of one machine: 22 of 22 snapshots under
`~/.claude/shell-snapshots/` restore `dotglob`, `nullglob`, `failglob`,
`globstar`, `nocaseglob` and `extglob` unset. A snapshot is what the Bash tool
starts its shell from, and it carries a `shopt -s` or `shopt -u` line for every
option the interactive shell had when it was taken. So on a machine whose
`.bashrc` sets `dotglob`, every pattern the tool's shell expands reaches hidden
files, and the filter in [`internal/hook/glob.go`](../../internal/hook/glob.go)
drops them -- a coverage gap of exactly the hidden files, on exactly the
machines that opted into them. `nocaseglob` and `globstar` widen the set the
same way; `nullglob` and `failglob` narrow it, which is the harmless direction.

The command string is covered -- a `shopt` in it puts the pattern back on the
record, `TestAGlobBashWouldExpandDifferentlyIsRecorded` -- and the environment
was driven and does not carry it: bash 5.3.15 ignores GLOBIGNORE from its
environment, and `shopt` state is not exported at all. What the hook cannot see
is the shell it never runs in.

**Two instruments, neither driven.** The snapshots are files the hook could
read: a `shopt -s dotglob` line in any of them means some tool shell on this
machine globs that way, and poisoning the expansion on that is fail-closed and
cheap. But the hook does not know which snapshot the current session sources,
the directory is Claude Code's own and undocumented, and reading it is a new
read outside the workspace that `PRIVACY.md` would have to carry. The other is
to stop filtering and scan the superset, which is the precision direction -- a
block on a hidden file the command never sends -- and precision is the product.

**Measure:** measure before choosing. How many machines set a glob option in an rc
file is not knowable from here. What is: whether the snapshot's `shopt` lines
track the rc file (they read as `shopt -p` output, and that has been read, not
driven), and whether a hook Claude Code invokes can find the snapshot its own
session uses. Take both before deciding between a read, the superset, and a
documented residual.
