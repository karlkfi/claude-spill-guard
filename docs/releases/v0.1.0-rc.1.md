**A rehearsal of the v0.1.0 publish path. Do not install this.**

> [!CAUTION]
> This prerelease exists to drive the three steps no pull request can reach — cosign signing, the build provenance attestation, and the asset upload. It is deleted once those pass. Install [v0.1.0](https://github.com/karlkfi/claude-spill-guard/releases) instead.

The runbook at [`docs/development/release-process.md`](https://github.com/karlkfi/claude-spill-guard/blob/main/docs/development/release-process.md) requires a rehearsal before a first release, on the grounds that a signing path nobody has exercised first executes on a permanent version number otherwise. This is that rehearsal.

What it checks: that `goreleaser` builds five archives named as the install channels expect, that `checksums.txt` matches them, that cosign mints a signature whose `--certificate-identity` pins to this workflow at this tag, that the attestation is minted and attached as an asset, and that the published assets verify the way an outside consumer would check them.

Content is identical to v0.1.0. Read [that release's notes](https://github.com/karlkfi/claude-spill-guard/releases) for what the tool does and what it does not read.
