**A rehearsal of the v0.2.0 publish path, not a release to adopt.**

> [!CAUTION]
> This prerelease exists to drive the steps no pull request can reach — cosign signing, the build provenance attestation, and the asset upload — and it is **deleted once they pass**, at which point `--version v0.2.0-rc.1` stops resolving. It carries the same code as [v0.2.0](https://github.com/karlkfi/claude-spill-guard/releases), which follows within hours, so there is nothing here to gain and a dead install URL to lose. Nobody reaches it by accident: `install.sh` resolves `releases/latest`, which GitHub redirects past a prerelease.
>
> **One person should install it, once.** Whoever cut this tag — `release-process.md` asks for an install from the published draft on one machine, because that is the only occasion the signature verification inside the install scripts runs at all. CI drives them through `--rehearse`, which skips it: artifacts served from a loopback port carry no release provenance to check.

The runbook at [`docs/development/release-process.md`](https://github.com/karlkfi/claude-spill-guard/blob/main/docs/development/release-process.md) asks for a rehearsal when the publish path has changed. It has: `scripts/check-plugin-version.py` now runs against the tag before anything is built, so a release whose plugin manifests carry the wrong number stops the run rather than publishing archives that `claude plugin update` can never deliver. That assertion has never executed on a real tag, and the tag is where it first would.

What it checks: that `goreleaser` builds five archives named as the install channels expect, that `checksums.txt` matches them, that the manifest version check passes against the tag, that cosign mints a signature whose `--certificate-identity` pins to this workflow at this tag, that the attestation is minted and attached as an asset, that the published body is the notes file rather than an empty string, and that the published assets verify the way an outside consumer would check them.

Content is identical to v0.2.0. Read [that release's notes](https://github.com/karlkfi/claude-spill-guard/releases) for what changed since v0.1.0 and what the scanner still does not read.
