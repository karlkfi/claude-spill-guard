# What v0.6.0 is for

**Ship the fail-opens closed since v0.5.0, and the three found while closing
them.**

Since v0.5.0, `main` has closed six calls that read a file with no verdict, or
read the wrong one: a failed operand walk that discarded what it had already
collected (#198), a quote inside a substitution that closed nothing (#199), a
`cd` inside a subshell (#200), a command wrapper ahead of the reader (#202), a
`CDPATH` assigned earlier in the string (#203), and grep's per-line prefix in
front of a private key (#204). Those reach every user and are the reason to
cut.

**It is a minor and not a patch.** `main` also carries five `feat` commits
since v0.5.0: the recursive-grep output filter and its `filter` subcommand
(#191), the session, directory and operand in each coverage record (#189), the
binary version in each record (#193), `coverage --since` and `--file` (#192),
and the social preview and mark (#185). A patch was measured and set aside on
2026-10-25: cherry-picking the eight fixes onto `v0.5.0`, three conflict. Q204
conflicts in `bash.go`, `coverage.go`, `coverage_test.go`, `prompt.go` and two
queue rows; Q196 in `bash.go`, `grep.go` -- a file that exists only because of
#191 -- and one queue row; Q186 in `bash.go`. So a `v0.5.1` would carry three
of its fixes hand-ported onto a branch nothing has tested.

## The rows the tag waits for

Named in prose rather than linked, because each is deleted by the pull request
that completes it.

| Row | The gap |
|---|---|
| Q210 | a `#` that bash reads as text starts a comment here, so the command after it is never read. Three shapes, each a silent allow; the row's fourth, `FOO[a #b]=x cat k.env`, needs Q185's lexer arm and moved there |
| Q211 | a `$'…'` word is not decoded, so its operand defers and every reader in the call goes unscanned. Three shapes beside it -- `echo $'\' #' ; cat k.env` and two heredocs -- are silent allows |
| Q213 | an assignment through a `declare -n` nameref sets the aliased name, which the variable tracker never sees |

Q213's shape is 4 of 223,749 real `Bash` calls by its filer's count, and the
maintainer chose to gate on it anyway. Before tagging, re-drive each row's table on the release candidate's
binary, from its pull request's body.
