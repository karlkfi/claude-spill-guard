# What v0.5.0 is for

**Ship the three fail-opens closed since v0.4.1, without shipping the recall
Q163's fix cost on a zsh tool shell.**

Since v0.4.1, `main` has closed three calls that read a credential file with no
verdict: an append prefix, `LC_ALL+=C cat <key>` (#165); a subscripted prefix,
`FOO[0]=x cat <key>` (#175); and a `**` glob expanded as bash's where the tool
shell is zsh and recurses (#179). It also widened `private-key-block` to a
unified diff's added and removed lines (#176). Those reach every user and are
the reason to cut.

The tag was ready on 2026-09-26 at `abe6cf5` -- green, no open pull requests,
publish path unchanged since v0.4.1 -- and was held there. #179 refuses every
glob where the shell is not bash, so on zsh `cat *.env` over a key went from a
deny to no verdict. The maintainer chose the narrow fix over shipping the trade
with a warning, or tagging from before #179.

## The row the tag waits for

| Row | The gap |
|---|---|
| [Q194](../queue/Q194.md) | a plain `*` glob defers on a zsh tool shell where v0.4.1 blocked it. Refuse only what zsh expands differently |

**One row gates the tag.** When it merges, re-drive its table on the release
candidate's binary: that table is the release notes' evidence that no recall
was lost on zsh, and it has to be re-measured against the build that ships,
not carried over from the PR.

## What is out, and why it is named rather than dropped

- **[Q184](../queue/Q184.md)**, the rest of the zsh delta: word splitting, and
  anything else that is not globbing. Q194 takes only the globbing slice it
  needs, and Q184 stays an open question at its own rank.
- **[Q185](../queue/Q185.md)**, **[Q186](../queue/Q186.md)** and
  **[Q188](../queue/Q188.md)** -- three fail-opens filed during this window,
  each present on v0.4.1 as well, so none is a regression. They go in
  v0.5.0's *What it does not read* list instead of gating it.
- **[Q187](../queue/Q187.md)** and **[Q193](../queue/Q193.md)** -- diff shapes
  `private-key-block` still does not cross. Also disclosed rather than gated.
